# Счётчик в Docker

Приложение и Redis запускаются в двух контейнерах. Redis хранит значение счётчика.

Как запустить из папки с compose.yaml:

1. При первом запуске скопировать настройки командой cp .env.example .env
2. Запустить контейнеры командой docker compose up -d --build --wait
3. Открыть http://127.0.0.1:8080/ в браузере. В поле count будет текущее значение.

Чтобы прибавить единицу, выполнить в терминале:

curl -X POST http://127.0.0.1:8080/increment

Если обновить страницу, будет видно новое значение.

В файле .env можно поменять приветствие (GREETING) и порт на компьютере (APP_PORT). Если поставить APP_PORT=8081, в браузере и в команде curl нужно использовать порт 8081. После изменения настроек ещё раз выполнить docker compose up -d --wait.

Для остановки выполнить docker compose down. При следующем запуске счётчик продолжит с прежнего числа.
